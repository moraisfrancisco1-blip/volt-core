# VOLT CORE

AI Operations Center for observing, understanding and safely coordinating production software.

## v0.1 foundation

- Core API: FastAPI
- Web dashboard: React + Vite
- Monitoring: read-only by default
- Actions: explicit approval required
- Voice and external integrations: planned behind adapters

## Safety model

VOLT may observe, analyse and propose. Production changes require an approved command and an auditable execution path.
